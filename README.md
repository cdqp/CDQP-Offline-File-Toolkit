# CDQP Offline File Toolkit

A free, all-in-one browser toolkit for converting, optimizing, merging, splitting, and archiving files locally.

Everything runs directly in your browser: your files are never uploaded to a server.

## Features

* Convert files between compatible formats
* Optimize PDFs, images, audio, documents, and other supported files
* Merge compatible documents or group unrelated files into ZIP or RAR archives
* Split multi-page documents
* Convert PDF files to DOCX, TXT, HTML, PNG, JPG, ZIP, or RAR
* Convert fonts between TTF, OTF, WOFF, and CSS formats
* Recompress compatible archives
* Automatically prevent optimized files from becoming larger than the originals
* Dark and light themes
* Optional interface animations
* Responsive and accessible interface
* Fully offline operation

## How to Use

1. Download `CDQP_Offline_File_Toolkit.html`.
2. Open it with a modern web browser.
3. Select one of the available tools.
4. Drop or select your files.
5. Choose an available output format or operation.
6. Process and export the result.

No installation, account, or internet connection is required.

## Privacy

All processing is performed locally on your device. Your files remain private and are never transmitted to an external server.

## Browser Compatibility

For the best experience, use a recent version of:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Opera
* Safari

Some advanced conversions depend on browser capabilities and may not be available for every file format.

## Important Note

Changing a file extension is not the same as converting its contents. The toolkit only proposes operations that can be performed safely and locally. When semantic merging is impossible, files can still be grouped into a ZIP or RAR archive.
